Esta atividade tem como objetivo criar uma base de dados fictícia de alunos e usar essa base para treinar um modelo de machine learning capaz de prever a nota final de cada aluno. As informações usadas para fazer essa previsão foram as horas de estudo por semana, a frequência nas aulas, a quantidade de atividades entregues e a nota que o aluno tirou anteriormente.
Depois de treinar o modelo, foram calculadas algumas estatísticas para entender se as previsões estavam próximas da realidade, como a média, o desvio padrão e o intervalo de erro. Ao final, esses resultados foram interpretados para avaliar se o desempenho do modelo pode ser considerado bom.
